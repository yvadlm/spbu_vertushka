# Бот станций

## Запуск
1. Создайте бота в @BotFather, скопируйте токен.
2. `pip install -r requirements.txt` (нужен Python 3.10+)
3. Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN` и свой Telegram ID в `CHIEF_IDS` (ID можно узнать у @userinfobot).
4. Отредактируйте `stations.json`: для каждой станции `id`, `name`, `location` и `organizer_id` (Telegram ID организатора). Организатор привязывается к станции здесь.
5. `export $(cat .env | xargs) && python bot.py`

## Запуск через Docker
```
cp .env.example .env     # впишите BOT_TOKEN и CHIEF_IDS
mkdir -p data
docker compose up -d --build
docker compose logs -f   # посмотреть логи
```
После правки `stations.json` достаточно `docker compose restart`. База и CSV с баллами лежат в папке `data/` рядом с compose-файлом и переживают пересоздание контейнера.

Станции из `stations.json` подхватываются при каждом запуске. Если поменяли организаторов, перезапустите бота. Занятость станций при этом не сбрасывается.

Каждый организатор должен хотя бы раз нажать /start у бота, иначе Telegram не даст боту написать ему уведомление.

## Куда сохраняются баллы
- `data/bot.db` — основная база (SQLite).
- `data/scores_log.csv` — журнал, в который каждое `/ball` дописывается отдельной строкой и сразу сбрасывается на диск.
- `/export` у главного организатора присылает в чат CSV со всеми посещениями и журнал начислений.

Копируйте папку `data/` в конце дня.

## Правила
- Один капитан — одна команда (`/register 101`), номер группы в формате 1**.
- Команда может занимать только одну станцию за раз. Повторно на ту же станцию можно (по умолчанию). Чтобы запретить, поставьте `ALLOW_REVISIT=0`: тогда освобождённая станция не показывается в `/list` команде, которая на ней уже была.
- Повторный `/ball` по той же станции перезаписывает баллы за это посещение. Каждое начисление при этом остаётся в журнале.
- Капитан баллов не видит: бот ни разу не отправляет их в чат команды.
- `/busy <станция> <группа>`: организатор вручную занимает станцию за команду.
- Главному организатору доступны и команды организатора. Если у вас несколько станций, добавляйте номер: `/ball 8 16`.
